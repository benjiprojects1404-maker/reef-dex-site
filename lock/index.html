How it works

  • The lock records the tokens that actually arrived, so a token with a transfer tax is credited with what it really sent.
  • Only the lock's owner can withdraw, and only on or after the unlock date. The owner can push the date later (never earlier) or hand the lock to another address.
  • Reef's admin (a 2-of-3 multisig) can only change the fee and where it goes. It can't touch any lock, pause the contract or upgrade it.
  • LP tokens sent to the burn address are gone forever; a lock is for liquidity you want back later. Both count as "locked" on Reef.
