Security

Reef has not had an independent audit. What it has had is a published AI-assisted security review, randomised (fuzz) tests you can rerun yourself, source code verified on the explorer for every contract, and a single admin role held by a 2-of-3 hardware-wallet multisig. This page sets out each of those, and what they don't cover.

Security review (2 Oct 2026)

Every Reef contract was read line by line, tested with attacks, and matched to its published source on chain. The review found no critical or high-severity issues. It is an AI-assisted review, not an audit by an independent firm.

Read the full review (hosted with the reviews of Nodal and Handshake).

Tests (4 Nov 2026)

  • Pools and router: eight safety rules held across 200,000 random trades across token and native BDAG pools, including that the router never keeps anything between trades and every WBDAG is backed 1:1 by BDAG.
  • Vesting, airdrop and oracle: fuzz tests run 10,000 times each with random inputs.
  • Each test was also checked by breaking the contract on purpose and confirming the test then fails.

The full list of rules, and how to rerun them, is in the docs.

Admin control

The Router and Factory have no owner: nobody can pause trading, block a wallet, freeze a pool or take your funds. The one privileged role is the Factory's feeToSetter, which only decides where the 0.05% protocol fee goes. It is held by a 2-of-3 multisig (0x4E24…60fc) with three separate hardware-wallet signers, any two of which must approve.

Not done yet

  • An independent audit by a security firm. It is planned, to be paid for from Reef's own fees once they allow it.
  • Fuzz tests of the admin multisig (it has its own tests), the presale contract, and removing liquidity with a signed permit.

Passing tests can't prove there are no bugs. Only trade or provide liquidity with amounts you are fully comfortable losing.
